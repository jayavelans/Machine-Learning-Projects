# K-Nearest Neighbors (KNN)

This folder contains my implementation and experiments with the
K-Nearest Neighbors (KNN) algorithm using Python and scikit-learn.

## Notebooks
- `iris.ipynb`  
  - Dataset: Iris  
  - Features: Continuous numerical data  
  - Preprocessing: MinMaxScaler  
  - Distance metric: Euclidean  
  - Model selection: Accuracy vs K  

- `mushroom.ipynb`  
  - Dataset: Mushroom  
  - Features: Categorical data  
  - Preprocessing: Label Encoding  
  - Distance metric: Hamming  
  - Evaluation: Confusion matrix and accuracy  

## Key Learnings
- Importance of choosing the correct distance metric
- Effect of scaling on KNN
- Selecting the optimal value of K
- Handling categorical vs numerical data
